# Tails Funkin BETA 0.1

Это фан-мод для Friday Night Funkin.

## О проекте
Этот проект содержит набор файлов и папок для игры, включая персонажей, музыкальные треки, изображения, события и данные игрового процесса.

## ⚠️ Важно
**Если есть косяки не судите строго, я новичок в программировании!**

## Структура проекта
- `characters/` — персонажи и их данные
- `custom-events/` — кастомные события игры
- `custom-notetypes/` — нестандартные типы нот
- `data/` — игровые данные и конфигурации
- `images/` — изображения и графика
- `readme/` — папка с дополнительной документацией
- `scripts/` — скрипты и логика
- `songs/` — музыкальные композиции и связанные файлы
- `stages/` — сцены и фоны
- `week/` — недели/уровни игры
- `pack.json` — файл конфигурации пакета

## Как скачать
Нажмите кнопку "Code" вверху страницы, затем выберите "Download ZIP".

## Как установить
1. Скачайте архив репозитория
2. Распакуйте его
3. Поместите файлы в папку вашего мода для Friday Night Funkin
4. Запустите игру
